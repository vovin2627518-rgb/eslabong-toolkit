# Eslabong 세이브 도구 2.1.0

원본 게임의 세이브 에디터와 선수 분석기를 하나의 실행기로 엽니다. 지오맨서는 저장값 편집만 지원하며, 알 수 없는 모드 클래스는 표시 전용으로 보존합니다. 이 저장소는 배포 파일과 안내 전용이며 소스 코드는 포함하지 않습니다.

## 다운로드와 실행

[최신 릴리스](https://github.com/vovin2627518-rgb/eslabong-toolkit/releases/latest)의 `eslabong-toolkit-2.1.0.zip`을 새 폴더에 모두 풀고 `eslabong-toolkit.exe`를 실행하세요. `_internal` 폴더도 필요합니다. 첫 화면에서 `eslabong.exe`와 `eslabong.pck`가 있는 게임 폴더를 선택합니다.

## 업데이트

실행 시 한 번 백그라운드로 확인하며, 오프라인에서는 알림을 띄우지 않습니다. [업데이트 확인]으로 수동 확인하고, [자세히]로 변경 사항을 볼 수 있습니다. 편집을 저장하거나 되돌린 뒤 [게임 연결 해제] → [업데이트 설치]를 누르세요. 서명과 SHA256을 검사한 전체 패키지로 교체하고 다시 실행합니다. 시작에 실패하면 기존 버전으로 복구합니다. 이전 패키지는 설치 폴더 옆 `*-update-*/previous`에 남습니다. 설치 위치에 쓰기 권한이 필요합니다.

## 안전과 제한

- 게임을 종료하고 세이브 사본으로 먼저 확인하세요. 게임 실행 중 저장은 차단됩니다.
- 저장 때 `.save-tools-backups`에 최근 5개 백업을 보관합니다. 보호 세이브는 새 이름으로만 저장할 수 있으며 승인 영수증은 발급하지 않습니다.
- 업데이트는 게임 폴더, 세이브, 설정, `%LOCALAPPDATA%\Eslabong_SaveTools`의 격리 엔진 데이터를 변경하지 않습니다.
- 원본 스킬 설명과 타 클래스 스킬 선택을 지원합니다. 보장 스킬 교체의 게임 내 유지는 모드로더 1.1.0 이상(6G 기능 포함)이 필요하며 기본 공격·대시는 고정입니다.
- 지오맨서 엔진 계산과 설치된 모드로더 기준 계산은 지원하지 않습니다.
